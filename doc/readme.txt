Как обновить библиотеку

1. Скачать обновленный дамп с исходными файлами-архивами + файл индекса .inpx
2. Скопировать их во временный каталог (файлы будут изменены в дальнейшем)
3. Использовать программу Cleaner для очистки, она удалит лишнее из архивов
4. Создать каталог для книг, который будет содержать обновленную библиотеку
5. Использовать скрипт fb2sort.py для каждого из очищенных файлов, создаст структуру в целевом каталоге
6. Импортировать полученную библиотеку в MyHomeLib, указав каталог с файлами (имя файла коллекции просто написать, не выбирать, он будет создан программой)
7. Выполнить экспорт коллекции в файл .inpx

process.py -s --archive-dir x:\Library\src\lib.rus.ec-clean --work-dir x:\Library --log y:\library.log
